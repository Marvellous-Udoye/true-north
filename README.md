# TrueNorth Talent Advisory

TrueNorth Talent Advisory helps organizations and professionals navigate the talent landscape with strategic recruitment, executive search, and career services. We operate across Technology, SaaS, Engineering, Operations, Supply Chain, Logistics, Corporate Services, and Professional Services.

## What We Offer

- **Client-facing services:** Executive Search Consultation, Strategic Recruitment Advisory, Custom Talent Solutions.
- **Candidate-facing services:** Career Consultation, Resume/Profile Review, Interview Coaching & Preparation, Job Matching & Placement.
- **Approach:** Tailored strategies, measurable outcomes, and cross-industry expertise for teams of all sizes.

## Tech Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- `next/font` with Plus Jakarta Sans

## Getting Started

```bash
npm install
npm run dev
# app runs on http://localhost:3000
```

## Project Notes

- Global metadata is configured in `src/app/layout.tsx` with Plus Jakarta Sans and a TrueNorth-focused SEO/Open Graph setup.
- Public icons referenced in metadata should live in `/public` (e.g., `favicon-32x32.png`, `apple-touch-icon.png`, `manifest.json`).
- Core styling lives in `src/app/globals.css`; main page content starts from `src/app/page.tsx`.
